**RF:** RF-03 · **Brecha:** B-02 (mediciones esporádicas) · **Rama:** `feature/hu03-lecturas`

**Como** Operario **quiero** registrar lecturas de temperatura, oxígeno disuelto y pH (manualmente o desde el sensor simulado) **para** tener mediciones frecuentes y confiables.

### Criterios de aceptación
- **CP-RF03-01** — **Dado** un estanque existente, **cuando** se registra una lectura válida por formulario o `POST /api/lecturas`, **entonces** se guarda con usuario y fecha/hora y es la última lectura visible en el panel en < 2 s.
- **CP-RF03-02** — **Dado** el registro de lectura, **cuando** se envía un valor físicamente imposible (pH fuera de 0–14, OD < 0, temperatura fuera de 0–40 °C), **entonces** se rechaza con **422** indicando el parámetro inválido.
- El simulador `python -m src.adapters.inbound.simulator --estanque 1 --escenario normal --intervalo 5` envía lecturas periódicas.
