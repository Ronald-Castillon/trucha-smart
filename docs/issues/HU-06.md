**RF:** RF-06 · **Brecha:** B-08 (alimentación empírica sin FCR) · **Rama:** `feature/hu06-alimentacion`

**Como** Operario **quiero** registrar el alimento suministrado (kg) y la mortalidad (n.º de peces) **para** que el sistema calcule biomasa y FCR del lote.

### Criterios de aceptación
- **CP-RF06-01** — **Dado** un lote activo, **cuando** registro alimentación y mortalidad, **entonces** la biomasa estimada = peces vivos × peso medio y el FCR = alimento total / ganancia de biomasa.
- **CP-RF06-02** — **Dado** un lote sin ganancia de biomasa (ganancia = 0), **cuando** consulto el FCR, **entonces** el sistema muestra "no calculable" sin error.
- Una mortalidad mayor que los peces vivos se rechaza con 422.
