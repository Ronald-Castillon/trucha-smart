**RF:** RF-01 · **Brecha:** B-04 (sin control de quién registra) · **Rama:** `feature/hu01-autenticacion`

**Como** Administrador **quiero** registrar usuarios con un rol (Administrador, Piscicultor, Operario) y que cada uno inicie sesión **para** saber quién registra cada dato y limitar lo que puede hacer.

### Criterios de aceptación
- **CP-RF01-01** — **Dado** un usuario registrado con rol Operario, **cuando** inicia sesión con credenciales correctas, **entonces** recibe un token JWT (cookie HttpOnly en web, Bearer en API) y accede al panel.
- **CP-RF01-02** — **Dado** un usuario registrado, **cuando** intenta iniciar sesión con contraseña incorrecta o usuario inexistente, **entonces** el sistema responde **401** con el mensaje "Usuario o contraseña incorrectos" y no emite token.
- **Dado** un Operario autenticado, **cuando** intenta crear un usuario o un estanque, **entonces** recibe **403**.

### Permisos
| Acción | Operario | Piscicultor | Administrador |
|---|---|---|---|
| Registrar lecturas, alimentación, mortalidad; atender alertas | ✔ | ✔ | ✔ |
| Gestionar estanques/lotes; reportes | | ✔ | ✔ |
| Gestionar usuarios | | | ✔ |
