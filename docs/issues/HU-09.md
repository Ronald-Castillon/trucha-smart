**RF:** RF-09 · **FURPS+:** F (integración), + (seguridad de acceso) · **Rama:** `feature/hu09-api-externa`

**Como** Administrador **quiero** emitir claves de integración para que sistemas externos (por ejemplo, el ERP o la empresa de alimento) consulten los datos de la piscigranja en JSON **para** no tener que exportar archivos a mano.

### Criterios de aceptación
- **CP-RF09-01** — **Dado** un sistema externo con una clave de integración activa, **cuando** consume `GET /api/externa/v1/estanques` o `/api/externa/v1/estanques/{id}/lecturas` con la cabecera `X-API-Key`, **entonces** recibe JSON con el estado de los estanques o sus lecturas por rango de fechas.
- **CP-RF09-02** — **Dado** una clave inexistente o revocada, **cuando** se consume la API externa, **entonces** responde **401** y no entrega datos.
- La clave completa se muestra una sola vez al crearla; en la BD solo se guarda su hash (SHA-256).

### Tareas
- [ ] Dominio: `ClaveIntegracion`, generación y verificación de claves.
- [ ] Puertos: `gestionar_integraciones`; `RepositorioClaveIntegracion`.
- [ ] Adaptadores: API externa de solo lectura, administración de claves (API y web).
- [ ] Pruebas CP-RF09-01/02 y capturas `evidencias/inc3/RF09_*`.
